# LinePulse Desk 条纹测量台

在有已知逐线读出时长的照片上检查条纹亮度。每份测试卡可放一张或两张照片，分别框选位置、选择按行或按列、保存读出和曝光参数、查看逐线亮度与表观频谱；两张照片还可做折叠别名后的共同闪烁频率核对与双试放导出。合成练习用同一图案的两次不同读出说明可见峰值。

## 启动

运行 `docker compose up --build -d` 后打开 `http://127.0.0.1:19910/`。设置 `LINEPULSE_PORT` 可换本机端口。用 `docker compose stop` 停止服务，命名卷保存测试卡。也可在 Python 3.11 或 3.12 环境安装 `requirements.txt`，执行 `./start.sh`。

## 使用

1. 导入 A 或 A、B 两张拍摄，或打开明确标明合成的练习。支持单帧 PNG、JPEG、TIFF、BMP、WebP，每张不超过 18 MiB、400 万像素，边长 32 至 2600 px。
2. 在各自的原图输入或拖出矩形范围，填写对应的实际读出方向、用时和曝光。相片来自同一扫描方向时，可直接切换对照逐线亮度。点原图或图表能核对同一原图读出线。
3. 表观频率只使用实际取到的逐线序列，采样上限显示为该读出的奈奎斯特频率。试放用用户填写的频率，分别拟合每张的亮度、幅度和相位。曝光时间留作拍摄记录。读数不能代替校验传感器真实读出时序。
4. A、B 两卡可在“共同闪烁频率”中填写真实频率范围、峰最低幅度和允许频率差。服务端把候选真实频率按各自每线用时折叠成表观频率，只保留两张都匹配到超门槛实际峰的候选；无匹配或仅单张匹配不会成为共同频率。建议候选会综合两峰强度和较弱峰的明显程度，采用后两张图都加入紫色共同试放曲线，并在 CSV 增加 `common_fit` 列（原有 `fit` 为各照片的手动试放）。之后若修改任一照片的选区、读出方向或每线用时，旧共同试放会标记为待重新核对；各照片的手动试放仍独立可用。
5. 可下载当前照片的逐线 CSV、校样 PNG，或两张原图和两份逐线数据的 ZIP。当前原图也可复制到照片准备工程，原始测试卡保留。
