# LinePulse Desk 条纹测量台

在有已知逐线读出时长的照片上检查条纹亮度。每份测试卡可放一张或两张照片，分别框选位置、选择按行或按列、保存读出和曝光参数、查看逐线亮度与表观频谱。合成练习用同一图案的两次不同读出说明可见峰值。

## 启动

运行 `docker compose up --build -d` 后打开 `http://127.0.0.1:19910/`。设置 `LINEPULSE_PORT` 可换本机端口。用 `docker compose stop` 停止服务，命名卷保存测试卡。也可在 Python 3.11 或 3.12 环境安装 `requirements.txt`，执行 `./start.sh`。

## 使用

1. 导入 A 或 A、B 两张拍摄，或打开明确标明合成的练习。支持单帧 PNG、JPEG、TIFF、BMP、WebP，每张不超过 18 MiB、400 万像素，边长 32 至 2600 px。
2. 在各自的原图输入或拖出矩形范围，填写对应的实际读出方向、用时和曝光。相片来自同一扫描方向时，可直接切换对照逐线亮度。点原图或图表能核对同一原图读出线。
3. A、B 两图都在时，可用「双图按行对应」：填行号差上限后按图像内容生成并自动采用一份对应。比较沿用两图已框区域，从各自框左相同偏移取行内亮度纹样（逐行 z-score，整行亮暗变化不影响），不调整两图横坐标；动态规划保证 A/B 两侧都不复用、行号严格递增且行号差不超过上限，光秃或纹样过弱的行留空。点 A 图或逐线图中的行，原点读区会显示 B 对应原行与实际亮度，可一键切到 B 查看该条；未配上的行显示“缺少对应”。
4. 表观频率只使用实际取到的逐线序列，采样上限显示为该读出的奈奎斯特频率。试放用用户填写的频率，分别拟合每张的亮度、幅度和相位。曝光时间留作拍摄记录。读数不能代替校验传感器真实读出时序。
5. 可下载当前照片的逐线 CSV、校样 PNG，或两张原图和两份逐线数据的 ZIP。当前原图也可复制到照片准备工程，原始测试卡保留。

行对应也有 HTTP 接口：`GET /linepulse/cards/<id>/correspondence?limit=<最大行号差>` 只计算候选，`POST /linepulse/cards/<id>/correspondence`（可带 `revision`、`limit` 或显式 `pairs`）计算并采用；`/match`、`/mapping`、`/alignment` 等路径与 `/line/<slot>` 返回的 `counterpart` 同义。
